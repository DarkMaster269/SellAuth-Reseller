# files.md — Manifest of every file and why it exists

Columns: **Path** | **Stage** | **Type** | **How to create** | **Purpose**

"Stage" is the stage in `detailed_implementation_plan.md` where the file
first appears. Later stages may edit it.

"How to create" is one of:

- **scratch**: write from scratch.
- **from ref**: adapt the named file in `DraxonV1/RESellAuth@7359c9e`.
- **from doc**: adapt from the linked SellAuth docs page.
- **from fixture**: generated from a real artifact the human saved.
- **template**: copy the template shown in this file.
